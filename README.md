# Kanban Board (Trello-like)

Навчальний проєкт — реалізація Kanban-дошки (аналог Trello) на чистому JavaScript без використання фреймворків.

Проєкт створений для практики роботи з DOM, управління станом застосунку, HTML5 Drag & Drop API та збереження даних у браузері.

---

## Технології

- Vanilla JavaScript (ES6+)
- HTML5 Drag & Drop API
- SCSS (BEM methodology)
- Vite (dev server + build)
- localStorage
- Vercel (Live / Staging)

---

## Функціональність

- Додавання необмеженої кількості колонок
- Додавання карток у колонки
- Редагування та видалення карток
- Перетягування карток між колонками (Drag & Drop)
- Збереження стану дошки після перезавантаження сторінки
- Адаптивний інтерфейс з горизонтальним скролом колонок

---

## Запуск проєкту локально

1. Встановити залежності:
npm install
2.	Запустити dev-сервер:
npm run dev
3.	Збірка проєкту:
npm run build
4.	Перегляд production-збірки:
npm run preview

---

## Деплой

Проєкт розгорнутий на Vercel з двома середовищами:
	•	Live — гілка master
	•	Staging — гілка development
